## Project Name
Piggy's Journey: An Educational Interactive Story

## One-Line Description
An interactive financial literacy game that teaches children smart saving habits through everyday choices and connects learning with a real Stellar wallet.

## Track
Track 5 Social Impact

## Problem It Solves
Many children learn about saving and budgeting only through lectures or experience, making financial concepts difficult to understand and practice. Piggy's Journey provides an interactive story where players make everyday spending decisions and immediately see how those choices affect their savings. After completing the story, users can connect a Stellar wallet and set a real savings goal, encouraging them to apply the lessons they learned beyond the game.

## How It Uses Stellar
The application integrates the Freighter wallet using the Stellar Freighter API, allowing users to securely connect their Stellar account. It uses Stellar Testnet to demonstrate wallet connectivity and savings goal functionality through the provided workshop components, including account funding, trustline management, balance viewing, and savings goal interactions. The project combines financial education with practical exposure to the Stellar ecosystem.

## Novelty Note 
Unlike traditional budgeting or expense tracker applications, Piggy's Journey focuses on financial education through an interactive narrative designed for children. Rather than simply displaying balances, it teaches the reasoning behind saving and spending decisions before introducing users to Stellar wallet functionality, making blockchain technology approachable for first-time users.

## Anything Else
This project was built as a prototype for educational purposes. Future improvements include additional story chapters, randomized events, achievement badges, sound effects, progress tracking, multilingual support, and on-chain reward mechanics using Soroban smart contracts to further encourage positive saving habits.
